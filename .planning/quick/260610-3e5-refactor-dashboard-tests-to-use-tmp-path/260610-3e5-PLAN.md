# Quick Task 260610-3e5: Refactor dashboard tests to use tmp_path

## Problem

`tests/test_compliance_dashboard.py` and `tests/test_dashboard_compliance_tab.py` pass bare
relative paths ("empty-dashboard.db", "populated-dashboard.db", "visual-dashboard.db") into
`render_compliance_tab`. The unmocked `load_extraction_run_summaries` call inside it opens
`sqlite3.connect(db_path)`, which creates 0-byte files in whatever directory pytest runs from —
i.e. the repo root.

## Tasks

### Task 1: Route db paths through pytest tmp_path
- **Files:** tests/test_compliance_dashboard.py, tests/test_dashboard_compliance_tab.py
- **Action:** Add `tmp_path` to the affected test signatures, build
  `db_path = str(tmp_path / "<name>.db")`, pass it to `render_compliance_tab`, and update the
  assertions that embed the path (empty-state caption text, `image_calls` tuples) to use the
  variable. Affected tests: `test_render_compliance_tab_empty_state_does_not_crash`,
  `test_render_compliance_tab_populated_source_detail_is_lazy_and_tolerates_missing_image`,
  `test_render_compliance_tab_source_detail_image_lookup_uses_selected_run_row`,
  `test_compliance_tab_empty_state_uses_shared_copy`.
- **Verify:** `venv\Scripts\python.exe -m pytest tests/test_compliance_dashboard.py tests/test_dashboard_compliance_tab.py -q` passes; no `.db` files appear in repo root after the run.
- **Done:** No bare relative `.db` paths remain in either test file.

### Task 2: Remove stale 0-byte db junk from repo root
- **Files:** empty-dashboard.db, populated-dashboard.db (repo root, untracked)
- **Action:** Delete the stray files left behind by previous test runs (only if 0-byte/untracked).
- **Verify:** Repo root contains no dashboard test db files after the test run.
- **Done:** Root is clean.
