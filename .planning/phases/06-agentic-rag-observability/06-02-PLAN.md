Build the HITL data layer: an append-only `extraction_reviews` audit table, a `"human"` evidence tier, and a review repository that lists low-confidence/abstained fields and applies approve/correct/confirm-absent actions. Purpose: HITL-01 requires that "corrections update the Compliance DB". This plan is the headless, testable core. The Review tab (06-06) is a thin layer over it.
Output: schema migration, `src/extraction/review.py`, and repository/db tests.
