<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Supplier page text/images -> Gemini | Confidential document content crosses to the configured API only for a requested extraction call |
| Gemini response -> provider DTO | Provider-controlled JSON and metadata are untrusted until strict Pydantic and semantic validation complete |
| Google SDK -> adapter retry loop | Network retry ownership must not multiply attempts or costs |
| Usage metadata -> persistence/tracing consumers | Only model IDs, counters, cost, trace ID, status, and safe reason codes may leave the adapter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | Structured provider output | mitigate | Fixed six-key `extra=forbid` Pydantic envelope, second semantic validation, canonical adaptation order, and fail-closed abstention tests |
| T-02-01-02 | Spoofing | Provider model identity | mitigate | Store requested and response-resolved identity separately; exact-key price selection prefers a recognized resolved model and never guesses aliases |
| T-02-01-03 | Repudiation | Token/cost accounting | mitigate | Store candidate and thought tokens separately, retain pricing model, use a versioned exact July 2026 registry, and test arithmetic |
| T-02-01-04 | Information Disclosure | Provider failures and diagnostics | mitigate | Public exceptions include only provider/model/run/doc/error class; tests inject secrets, paths, page text, and raw payload sentinels and assert absence |
| T-02-01-05 | Denial of Service | Nested/unbounded retries | mitigate | One adapter-owned retry layer, SDK attempts disabled, 1..5 cap, bounded exponential jitter, and no retry for nontransient failures |
| T-02-01-06 | Tampering | Visual requested-field subset | mitigate | Validate the complete fixed-six envelope before applying the local requested-field allowlist; provider cannot introduce an arbitrary field name |
</threat_model>
