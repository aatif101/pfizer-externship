<objective>
Turn extraction run history into a durable, resumable batch state machine. Add an immutable run identity and per-document manifest rows, migrate existing databases conservatively, make terminal status a SQL-derived batch fact, and coordinate single/batch CLI commands so failures, retries, resumes, and interruptions are auditable without ever exposing document content.

Purpose: Current persistence marks a shared run completed after each successful document and cannot record a failed document or prove that a run covered a stable corpus/model. Reliable demo numbers require terminal, reproducible source runs rather than console-local counters.
Output: additive lifecycle/provenance schema, typed run DTOs, transactional repository API, resumable CLI coordinator, legacy backfill, and offline lifecycle/migration tests.
</objective>

```python
class ExtractionRunStatus(StrEnum):
    RUNNING = "running"
    COMPLETED = "completed"
    PARTIAL = "partial"
    FAILED = "failed"

class ExtractionDocumentStatus(StrEnum):
    PENDING = "pending"
    RUNNING = "running"
    COMPLETED = "completed"
    FAILED = "failed"

def begin_or_resume_extraction_run(
    db_path: str,
    *,
    run_id: str,
    doc_ids: tuple[str, ...],
    provider: str,
    requested_model: str,
    corpus_version: str,
) -> ExtractionRunSummary: ...

def list_resume_candidates(db_path: str, run_id: str) -> tuple[ExtractionRunDocument, ...]: ...
def mark_run_document_running(db_path: str, run_id: str, doc_id: str) -> ExtractionRunDocument: ...
def mark_run_document_completed(db_path: str, run_id: str, doc_id: str, *, trace_id: str | None = None) -> None: ...
def mark_run_document_failed(db_path: str, run_id: str, doc_id: str, *, reason_code: str) -> None: ...
def finalize_extraction_run(db_path: str, run_id: str) -> ExtractionRunSummary: ...
def get_complete_extraction_run(db_path: str, run_id: str) -> ExtractionRunSummary | None: ...
def record_extraction_run_resolved_model(db_path: str, run_id: str, resolved_model: str | None) -> None: ...
```

```text
sha256("corpus_version\x1f" + each sorted unique doc_id separated by "\x1e")
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI options/document catalog -> run identity | User-provided run/corpus identifiers and local document IDs define a reproducible manifest |
| Batch coordinator -> SQLite lifecycle | Process-local events become durable parent/child transitions and aggregate terminal state |
| Legacy SQLite -> migrated schema | Existing extraction evidence/compliance history must survive additive migration/backfill |
| Provider/pipeline failures -> lifecycle rows/operator output | Arbitrary exceptions must be reduced to stable reason codes before persistence or display |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Spoofing | Reused run ID | mitigate | Immutable exact manifest/provider/requested-model/corpus comparison rejects mismatches before provider work or mutation |
| T-02-02-02 | Tampering | Premature run completion | mitigate | Only `finalize_extraction_run` derives terminal state from all child rows; per-record upsert cannot finalize a managed batch |
| T-02-02-03 | Repudiation | Failed/interrupted documents | mitigate | Per-document status, attempts, timestamps, trace ID, and safe reason code persist; interrupted rows remain running/resume-eligible |
| T-02-02-04 | Information Disclosure | Manifest, errors, CLI, DTOs | mitigate | Hash only corpus version/doc IDs; strict metadata/column allowlists; never persist/print raw errors, paths, content, images, payloads, or keys |
| T-02-02-05 | Tampering | Legacy migration/backfill | mitigate | Guarded additive ALTERs, parameterized backfill, idempotent init, no table rebuild, and before/after row/FK/index tests |
| T-02-02-06 | Denial of Service | Unbounded resume loop | mitigate | One deterministic pass over finite manifest candidates per invocation; attempt count is bounded scalar and completed documents are skipped |
| T-02-02-07 | Elevation of Privilege | SQL metacharacters in IDs | mitigate | Parameterize all data values; static migration identifiers come only from code-owned tuples; hostile-ID round-trip tests |
</threat_model>
