<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Validated provider candidate -> accepted field | Structurally valid model output still must prove literal source/page support and packet semantics |
| Page image -> visual evidence | Image-only claims lack text-verbatim verification and therefore must remain human-reviewable |
| Accepted fields -> compliance risk | Uncertain/abstained/visual evidence must never create false-safe compliance |
| Provider usage -> SQLite/eval provenance | Only bounded identity/counter/cost facts may persist or enter traces |
| Extraction run -> evaluation | Metrics are meaningful only for a complete immutable manifest with zero failures |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | Provider evidence/page claim | mitigate | Valid page plus exact stored substring for text; image-backed empty-text page only for visual; invalid/fuzzy claims abstain |
| T-02-03-02 | Spoofing | Packet/trap date | mitigate | Prompt scope plus deterministic Delivery/Retest/email/SDS/template/processing/attachment guards and adversarial packet fixtures |
| T-02-03-03 | Tampering | Compliance risk from uncertainty | mitigate | Pure calendar policy, expired-red precedence, forced review for low-confidence/visual evidence, and no compliant status from uncertain inputs |
| T-02-03-04 | Repudiation | Incomplete benchmark source | mitigate | Strict completed-run/count gate, immutable manifest/model/corpus provenance, and zero metrics on refusal |
| T-02-03-05 | Information Disclosure | Traces, rows, params, failures | mitigate | Explicit metadata/column allowlists and forbidden-sentinel tests across text, visual, usage, and eval paths |
| T-02-03-06 | Denial of Service | Text-empty or malformed provider paths | mitigate | Skip text call on empty pages, one bounded visual attempt path, compact span limit, safe abstention, and finite offline gates |
| T-02-03-07 | Spoofing | Resolved model changes within run | mitigate | First bounded resolved identity is immutable; conflicts fail with `extraction_run_model_mismatch` |
</threat_model>
