| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-02 | Information Disclosure | Qdrant upsert payload (collection.py) | mitigate | Payload restricted to {doc_id, page_num}; grep proves no image_blob/page_text keys; no bytes value present |
| T-05-03 | Tampering | init_db idempotent migration | mitigate | `_migrate_visual_index_runs_table` is additive ALTER guarded by `_table_columns`; test runs init_db twice and asserts no error + stable columns |
